📱 Smartprix Mobile Data Scraper

A Python web scraping mini project that extracts mobile product data from Smartprix using Selenium and Beautiful Soup.

The project automates webpage scrolling, stores HTML locally using Python file handling, and parses the saved HTML to create a structured Pandas DataFrame for analysis.

🚀 Features
Automated web scraping using Selenium
Handles dynamic webpage scrolling
Stores HTML locally for efficient processing
Parses HTML using BeautifulSoup
Extracts mobile product details
Creates structured Pandas DataFrames
🛠️ Technologies Used
Python
Selenium
BeautifulSoup4
Pandas
📂 Workflow
Open Smartprix mobile webpage using Selenium
Automate scrolling to load complete data
Save webpage HTML locally
Parse HTML using BeautifulSoup
Extract mobile product information
Store extracted data in a Pandas DataFrame
📊 Extracted Data
Mobile Name
Price
Ratings
Specifications
Product Links
📦 Installation
pip install selenium
pip install beautifulsoup4
pip install pandas
